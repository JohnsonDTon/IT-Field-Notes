Ventoy allows your USB to hold multiple ISOs, so you can boot based on what you need on the field. <br> <br>

Download Ventoy (Can be newer than 1.1.17)
```text
https://github.com/ventoy/Ventoy/releases → Ventoy 1.1.17 release → Assets → ventoy-1.1.17-windows.zip
```

Install Ventoy on USB
```text
Run Ventoy2Disk.exe -> Device: Your USB -> Install
```

Set up Memtest86 Free Version
```text
memtest86.com -> Extract memtest86-usb.img -> Put in Tools folder in the USB drive
```
